# 7-minute demo script
1. Open dashboard; explain local synthetic mode and show health-score formula.
2. Click each topology component; explain that the 3D-style map represents logical dependencies.
3. Show CPU observed history and baseline forecast. Open `/api/model/status` to show whether ML artifacts are trained.
4. Trigger Traffic spike; show metric update, rule diagnosis and incident timeline.
5. Trigger Database saturation; explain root-cause output is rule-based correlation, not causal ML.
6. Show Cost intelligence. If no verified hourly price is configured, demonstrate that the system refuses to invent a savings amount.
7. Approve a recommendation in local mode; show audit history and explicit message that no cloud resource changed.
8. Download the CSV and mention that actual CloudWatch mode is optional and read-only.
